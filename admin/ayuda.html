Cómo crear la clave de acceso del panel

Para Ronald. Se hace una sola vez, desde una computadora, con la cuenta de GitHub de Thalia Import (la dueña del repositorio …). Toma unos 5 minutos.

1. Crear la clave en GitHub

  1. Entra a github.com con la cuenta de GitHub de Thalia Import (usuario …). arriba a la derecha, la foto de perfil de esa cuenta. Si ves otra cuenta, cierra sesión y entra con la correcta.
  2. Toca la foto de perfil (arriba a la derecha) → Settings. un menú largo a la izquierda con "Public profile", "Account", "Appearance"…
  3. Baja hasta el final del menú de la izquierda → Developer settings.
  4. Elige Personal access tokens → Fine-grained tokens → botón verde Generate new token. un formulario titulado "New fine-grained personal access token". Puede pedir la contraseña o un código de confirmación.
  5. Token name: escribe Panel Thalia celular. En Description puedes poner Clave del panel de la tienda.
  6. Resource owner: deja la cuenta ….
  7. Expiration: elige No expiration si aparece en la lista. Si no aparece, elige Custom y la fecha más lejana que deje (GitHub suele permitir hasta 1 año) y anota en tu calendario renovarla unos días antes. un menú con 7, 30, 60, 90 días, "Custom" y a veces "No expiration".
  8. Repository access: marca Only select repositories y elige solo …. tres opciones redondas: "Public repositories (read-only)", "All repositories" y "Only select repositories". Debajo aparece un buscador de repositorios.
  9. Permissions → Repository permissions → busca Contents y cámbialo a Read and write. No toques nada más (GitHub agrega solo "Metadata: Read-only", es normal). una lista larga de permisos (Actions, Administration, Contents…), cada uno con un menú "No access". Solo Contents pasa a "Read and write".
  10. Baja y toca Generate token. Revisa el resumen y confirma.
  11. Aparece la clave: un texto largo que empieza con github_pat_. Cópiala ahora: GitHub no la vuelve a mostrar. un cuadro verde con la clave y un botón para copiar.

2. Dejarla en el celular de Thalia

  1. Mándate la clave a ti mismo de forma privada (o escríbela directo en su celular). No la publiques ni la mandes a grupos.
  2. En el celular de Thalia, abre … en Chrome.
  3. Pega la clave en Clave de acceso y toca Entrar. Debe aparecer la lista de zapatillas.
  4. En Chrome, menú ⋮ → Agregar a la pantalla principal, con el nombre Mi tienda. Así Thalia lo abre como una app.
  5. Borra el mensaje donde te mandaste la clave.

La clave queda guardada en ese celular. Si Thalia toca Salir, hay que volver a pegarla.

Si algo pasa

  • "Clave incorrecta o vencida": la clave venció o se borró. Crea una nueva (pasos de arriba) y pégala.
  • "Esta clave no tiene permiso para guardar": falta Contents: Read and write o no se eligió el repositorio. Edita la clave en GitHub o crea otra.
  • Se perdió o robaron el celular: en GitHub → Settings → Developer settings → Fine-grained tokens, entra a Panel Thalia celular y toca Delete. La clave deja de funcionar al instante.

Quien tenga la clave puede cambiar la tienda. Por eso tiene permiso solo sobre este repositorio y solo para su contenido.
